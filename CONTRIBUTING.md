# working on signal

scene markup, styles and interactions live in `site/sections`. `site/lib` owns state and language helpers. `brand-kit` contains the character, logo, favicon and licensed fonts.

from the repository root:

```bash
python3 site/build.py
python3 -m pytest -q site/tests
node --test site/tests/*.mjs
```

run `python3 site/serve.py --port 8799`, then check the interface in another terminal:

```bash
python3 site/verify.py
python3 site/verify_languages.py
```

check both languages, keyboard access and reduced motion when changing the interface. asset paths need to work from a subdirectory. build output in `site/assets`, `site/index.html` and `site/public` is regenerated by `site/build.py`.

`python3 docs/render_github.py` refreshes the screenshots used by both readme files from the running workshop. update the corresponding text and screenshots together when a feature changes.

keep local notes, agent prompts, execution plans and temporary output outside the public source tree. never commit credentials or personal data. the workshop runs locally in the browser without analytics or external apis.
