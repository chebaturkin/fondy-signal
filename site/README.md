# signal

`site` содержит статическую мастерскую signal на русском и английском. четыре сцены помогают собрать сигнал, сделать паузу, написать записку и сыграть ритм.

fondy сопровождает страницу в липкой боковой колонке. на экранах до 900 пикселей он занимает компактную полосу над сценами. подсказка меняется при выборе сцены и после действий. навигация обходится без нумерации и повторных надзаголовков.

## запуск

из корня репозитория:

```sh
python3 site/build.py
python3 site/serve.py --port 8799
```

откройте [локальную страницу](http://127.0.0.1:8799/). сборка работает без сети, читает исходники внутри репозитория и пишет результат в `site/public`.

## архитектура

- `sections/workshop.html`: разметка сцен, спутника и кнопок;
- `sections/workshop.css`: оформление, адаптивность и движение;
- `sections/workshop.js`: реакции fondy, подсказки, действия, экспорт и ссылки;
- `lib/workshop-state.js`: нормализация и кодирование состояния;
- `lib/messages.json` и `lib/i18n.js`: тексты и выбор языка;
- `base.css`: шрифты и общие переменные;
- `build.py`: сборка страницы, персонажа, логотипа, фавикона и шрифтов.

все ресурсы локальные. логотип и фавикон используют один знак: сложенный уголок fondy и линию пульса. слово signal в логотипе переведено в векторные контуры.

состояние хранится в части адреса после `#`. переходы к мастерской и содержимому сохраняют этот адрес. текст записки входит в ссылку и будет доступен её получателю.

## проверка

```sh
python3 site/build.py
python3 -m pytest -q site/tests
node --test site/tests/*.mjs
```

с работающим сервером запустите `python3 site/verify.py` и `python3 site/verify_languages.py`. они проверяют сцены, клавиатуру, размеры экрана, положение спутника, reduced motion, обе языковые версии и экспорт. снимки для двух readme обновляет `python3 docs/render_github.py`.
