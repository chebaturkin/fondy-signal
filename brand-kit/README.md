# signal: визуальные материалы

папка хранит персонажа fondy, логотип signal, фавикон и два локальных шрифта.

| путь | что здесь |
| --- | --- |
| `assets/mascot` | векторный персонаж fondy |
| `assets/favicons/signal-logo.svg` | логотип: знак со сложенным уголком и пульсом, слово signal в контурах |
| `assets/favicons/favicon.svg` | тот же знак для вкладки браузера |
| `fonts` | dela gothic one, onest и тексты лицензий |

`python3 site/build.py` копирует эти группы в `site/assets` и `site/public/assets`. получившиеся файлы не редактируй вручную.

## цвета и шрифты

кобальт `#2457FF`, оранжевый `#FF6B35`, тёплая бумага `#FFF4DF` и почти чёрный `#171717` составляют исходную палитру. в интерфейсе есть более светлые оттенки бумаги и кобальта для поверхностей.

dela gothic one используется в первом заголовке и логотипе. onest отвечает за текст и элементы управления. лицензии sil open font license лежат рядом с файлами шрифтов.
